## 2. 关键数据流

### 2.1 登录与账号持久化（Sprint 1）

```
用户输入手机号
  → uni-captcha 图形验证码
  → auth-gateway.sendSmsCode()
      ├─ 频控检查（同号 60s / 单日上限）    ← Sprint 1 新增
      ├─ CSPRNG 生成 6 位验证码             ← Sprint 1 替换 Math.random
      └─ 写入 opendb-verify-codes（含尝试计数）
  → 用户输入验证码
  → auth-gateway.loginBySms()
      ├─ 错误次数校验（5 次作废）            ← Sprint 1 新增
      ├─ 手机号类型严格校验                  ← Sprint 1 新增
      ├─ 调用 uni-id-co.loginBySms 签发 token
      └─ 扩展 uni-id-users 字段：
           login_count / last_login_at / source
  → 前端存储 token → 路由守卫放行
```

### 2.2 会话健康检查（Sprint 1）

```
冷启动 / 关键操作前
  → utils/session.js.ensureSession()
      → uniCloud.callFunction('session-audit')
          ├─ 校验当前 token
          ├─ 返回：剩余有效期 / 是否即将过期 / 登录设备数 / 最近登录地（IP 粗粒度）
      → 决策：
          剩余 > 阈值      → 放行
          剩余 ≤ 阈值     → 静默刷新 token
          token 已失效    → 强制重新登录
```

### 2.3 Agent 编排（Sprint 2）

```
用户输入
  → runAgent(input, context)                    agent/core/index.js
      ├─ planner.plan(input)
      │    ├─ adapters/rule-adapter（默认，零依赖）
      │    │    意图分类 → 置信度评分 → 工具序列
      │    └─ adapters/llm-adapter（可选，需 Key）
      ├─ 置信度 < 阈值？
      │    └─ 是 → fallback.capabilityList()      ← 不胡编，返回能力清单
      ├─ executor.run(plan, context)
      │    ├─ 工具注册表查表（tools/index.js）
      │    ├─ 参数 Schema 校验（失败返回结构化错误，不抛异常）
      │    └─ 串行执行 + 耗时统计
      ├─ memory 写入本轮上下文
      └─ trace 写入环形缓冲区（最近 20 条，前端可查）
```

### 2.4 数字人联动（Sprint 3）

```
Agent 回答用户
  → executor 调用工具 avatar-speak
      → AvatarController.speak(text)
          ├─ LipSyncBridge.build(text)
          │    文本 → 口型参数序列 [{t, value}]
          │    （默认纯规则映射，不依赖音频）
          ├─ TTS 适配器（默认 noop / 可选讯飞）
          └─ rAF 循环按时间轴驱动
              → canvasAvatar.setMouthOpenY(value)
              → canvasAvatar.render()
  → AvatarController.stop()
      → 立即打断 + 口型复位为 0
```

## 3. 设计原则

| 原则 | 落地方式 |
|---|---|
| **增强优先于重建** | 18 页面 / 5 组件 / 21 云函数全部复用；只在缺失处补齐 |
| **自研优先于拼装** | Agent 编排层与数字人交互层为自研代码，可在仓库内读、可测、可讲 |
| **零配置可运行** | 所有收费服务默认关闭，走本地降级路径；clone 即跑，零费用 |
| **密钥零入库** | 统一经 `app-config` 读取；源码只有占位符 |
| **失败可预期** | Agent 有降级链（能力清单），不返回错误工具结果 |
| **行为可观测** | 每次 Agent 调用产生 trace（输入/规划/耗时/输出） |
| **不破坏现有页面结构** | 新增能力以独立模块 + 新增页面方式接入 |
